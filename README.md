## Description
# Image Converter API

A RESTful Image Conversion API built with NestJS that allows users to upload images and convert them into different formats efficiently. Designed to be lightweight, scalable, and easy to integrate into web and mobile applications.

## Features

- Convert images between multiple formats
  - JPG / JPEG
  - PNG
  - WebP
  - GIF
  - BMP
  - TIFF (if supported)
- File upload support using multipart/form-data
- Input validation and error handling
- RESTful API architecture
- Built with NestJS and TypeScript
- Easy deployment and containerization

## Tech Stack

- NestJS
- TypeScript
- Sharp (or your image processing library)
- Multer
- Node.js

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/jiieea/image-converter-api.git
cd image-converter-api
```
